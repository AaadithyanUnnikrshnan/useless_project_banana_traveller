⚡ ABOUT HOW MANY BANANAS AWAY

How Many Bananas Away turns boring standard measurements into vibrant, humorous units of physical reality.

🛑 ABSOLUTE OBFUSCATION GUARANTEE:
Not a single metric (meter/km) or imperial (foot/mile) unit is ever presented to you. All distances are strictly translated into bananas, giraffes, football fields, and double-decker buses!

Absurd Reference Scales:

  • 🍌 Bananas — Canonical Cavendish fruit curve standard
  • 🦒 Giraffes — Towering savanna mammal crown-to-hoof stance
  • 🚌 Double-Decker Buses — Classic British commuter transit bumper-to-bumper
  • 🐋 Blue Whales — Colossal marine leviathan snout-to-tail fluke
  • 🏙️ City Blocks — Classic downtown pedestrian quadrangle
  • 🏈 Football Fields — Regulation championship gridiron endzone-to-endzone

Built with Web Geolocation API (Haversine formula + signal jitter filter), Leaflet.js, and pure Neo-Brutalist design.
